# คลังสไตล์อ้างอิง P3.5

ฐานหลักฐาน: `audits/p035-style-reference-analysis/report.md` ใน workspace ช่วยด้วยจ้า CapCut v1.4 ตรวจโครงสร้าง 30 ต.ค. 2026 เป็นหลักฐานจาก draft ไม่ใช่การรับรอง playback/export ไม่คัดลอกไฟล์สื่อหรือบัญชีจาก reference เข้า skill

## ใช้หลักฐานอย่างไร

| ระดับ | สิ่งที่บอกได้ | สิ่งที่ยังบอกไม่ได้ |
|---|---|---|
| โครงสร้าง draft | ข้อความ เวลา reference แทร็ก animation/keyframe references | ผลที่เห็น/ได้ยินจริงทุก instance |
| ไฟล์อยู่ | มีไฟล์ ณ path ที่ตรวจ | decode ได้ครบหรือ editor ใช้ไฟล์นั้นสำเร็จ |

จำนวน recursive เป็นจำนวนในนิยามย่อย ไม่ใช่จำนวนเหตุการณ์ที่ผู้ชมเห็น ข้อความซ้ำอาจเป็น slice/animation; audio รวมเพลงและเสียงประกอบ ไม่ใช่ SFX ล้วน ทุกงานพบ DB Heavent แต่ต่างน้ำหนัก ไม่ได้วัดขนาด/สี/ความดังร่วมที่ใช้ได้กับทุกงาน

## ตัวอย่างใช้กับเนื้อหาใหม่

คำพูดสมมติ: “เครื่องมือเปลี่ยน แต่หลักการยังใช้ได้ เราต้องเข้าใจผู้บริโภค”

เลือกตระกูลการตลาดเพราะมีคู่ความคิดโต้กัน ซับรักษาประโยคจริง ข้อความออกแบบเปิด “เครื่องมือเปลี่ยน” แล้วคง “หลักการยังใช้ได้” เป็นฐาน ก่อนเน้น “เข้าใจผู้บริโภค” เป็นข้อสรุป ใช้ motion เปลี่ยนเฉพาะชั้นเครื่องมือ และเสียงเบาหนึ่งจุดเมื่อจบความคิด หากคำพูดจริงยังมีข้อยกเว้นตามมาให้เก็บข้อยกเว้นนั้นด้วย เวลาและจังหวะทั้งหมดต้องอิงคลิปใหม่ ตัวอย่างนี้เป็นข้อเสนอ ไม่ใช่ reconstruction ที่พิสูจน์แล้ว
