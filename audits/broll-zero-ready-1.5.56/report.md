# B-roll 0/18 — P0.11

ผู้ใช้ยืนยันว่า log มาจากเครื่องอื่น ไม่พบ receipt งานนี้ในบัญชีเครื่องปัจจุบัน จึงยังยืนยันสาเหตุเฉพาะงานปลายทางไม่ได้

ตรวจซอร์สพบว่าแสดงคำค้นก่อนตรวจช่วง และข้ามบางเงื่อนไขโดยไม่เพิ่มตัวนับหรืออธิบาย ทำให้ log 0/18 ไม่บอกว่าเริ่มค้น Artlist แล้วหรือยัง อีกทั้งแทร็กภาพที่ปิดถูกนับเป็นภาพเดิมทับช่วง

แพตช์ 1.5.57 ไม่นับแทร็กที่ปิด แต่รักษาภาพเดิมที่เปิดอยู่; ตรวจกรณีภาพเดิมครอบคลุมทั้ง timeline ก่อนเรียก AI/stock; แจ้งเหตุผลและตัวนับทุกช่วงที่ข้าม; แยกจำนวนค้นจริง/ไม่พบ/ช่วงใช้ไม่ได้; เก็บสรุปใน receipt ที่ล้มเหลว และแสดงข้อความหยุดครั้งเดียว

หลักฐาน: Python 455 tests และ JavaScript 15 suites ผ่าน รวมกรณี 18 คำค้นถูกภาพเดิมขวาง: ไม่ค้น stock, ข้าม 18 ช่วง พร้อมเหตุผล และต้นฉบับไม่เปลี่ยน; hidden overlay ไม่ขวาง; visible overlay ยังได้รับการป้องกัน; timeline สั้นไม่ถูกกล่าวผิดว่าเป็นภาพเดิมขวาง

การทดสอบ AI/stock ใช้ค่าจำลอง ไม่ได้ทดลองบัญชีหรือโปรเจกต์บนเครื่องที่รายงาน และไม่ได้แก้โปรเจกต์จริง การยืนยันเหตุผลของงานนั้นต้องดู log รุ่นใหม่บนเครื่องปลายทาง
