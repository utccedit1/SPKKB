# โหมดหาและใส่ B-roll อัตโนมัติอย่างเดียว

สถานะ: เผยแพร่ในรุ่น 1.5.54 สำหรับทดลองใช้จริงแล้ว การทำงานผ่านเว็บ Artlist ยังขึ้นกับบัญชีและหน้าเว็บของผู้ให้บริการ

1. เลือกโปรเจกต์ที่ตัดต่อและมีซับพร้อมเวลาแล้ว เปิดหน้า **B-roll / มีม**
2. เลือก **ฟุตเทจ B-roll** แล้วกำหนดโทนภาพตามต้องการ เครื่องมือหาไอเดีย/คำค้นเดิมยังใช้ได้
3. ในส่วน **หาและใส่ B-roll อัตโนมัติ · Artlist** เลือกจำนวนภาพสูงสุด แล้วกด **หาและเตรียม B-roll** ใช้บัญชี Artlist/Stock Bridge และโฟลเดอร์สื่อของโปรเจกต์ที่เชื่อมไว้
4. รอค้น ดาวน์โหลด และตรวจไฟล์ ระบบเตรียมผลในสำเนา แสดงจำนวนภาพที่ใส่ได้และเหตุผลที่ข้ามบางช่วง
5. บันทึกแล้วออกจากโปรเจกต์กลับหน้าหลัก CapCut กด **ใส่เฉพาะ B-roll ในโปรเจกต์เดิม** แล้วเปิด CapCut ตรวจภาพก่อนส่งออก

เพิ่มเฉพาะแทร็กภาพใหม่ปิดเสียง ไม่เปลี่ยนรอยตัด/ความเร็ว/ซูมของคลิปเดิม ซับ ข้อความ เพลง ระดับเสียงเดิม และความยาวโปรเจกต์ ไม่สร้าง speaker PiP

ก่อนนำเข้า ระบบตรวจว่าต้นฉบับ/ไฟล์ผล/สื่อไม่เปลี่ยน และตรวจว่าการตัดต่อเดิมยังเหมือนเดิมทุกฟิลด์ หากตรวจไม่ผ่านจะหยุดแทนการแก้ส่วนอื่นให้เอง มี backup และกู้คืนจากประวัติได้

หากช่วงนั้นมีภาพประกอบเดิมอยู่แล้วจะข้าม ไม่ลบหรือแทนภาพเก่า มีมยังใช้หาไอเดีย/ลิงก์ค้นหาแบบเดิม และ Envato ยังไม่รองรับดาวน์โหลดอัตโนมัติในโหมดนี้

ผลที่สร้างเสร็จกลับมาตรวจได้หลังเปิดหน้าใหม่ หากต้นฉบับเปลี่ยนระหว่างค้นหรือก่อนนำเข้า ต้องตรวจใหม่ ไม่ใช้ผลเดิมทับโดยเงียบ ๆ บาง schema ที่แยกลำดับภาพใต้ซับเดิมไม่ได้จะถูกปฏิเสธเพื่อรักษาซับไว้

งานหลายภาพอาจใช้เกิน 30 นาที รุ่น 1.5.52 ไม่ตัด batch ด้วยเวลารวมนี้ แต่ยังจำกัดเวลารอ AI/ดาวน์โหลดแต่ละครั้ง ยกเลิกงานได้ ไฟล์ที่ดาวน์โหลดผ่านการตรวจแล้วเก็บในคลังและใช้ซ้ำได้เมื่อคำค้นตรงและ hash ยังถูกต้อง ผลที่ยังสร้างไม่เสร็จไม่ใช่ผลพร้อมนำเข้า

รุ่น 1.5.54 มีช่อง log แสดงเวลา ขั้นตอน คำค้น จำนวนภาพพร้อม/เป้าสูงสุด ดาวน์โหลดแล้ว และ byte progress เมื่อ Chrome ส่งมา จำนวนที่ยังขาดเป็นเป้าสูงสุด ไม่รับรองว่าจะพบภาพครบทุกช่วง

หาก B-roll ที่นำเข้าในรุ่นเก่าขึ้นสื่อหาย ให้บันทึกและกลับหน้าหลัก CapCut → กด **ตรวจซ่อมสื่อ B-roll ที่นำเข้าแล้ว** → อ่านผลตรวจ → **ยืนยันซ่อมสื่อ B-roll ในโปรเจกต์เดิม** แล้วเปิด CapCut ตรวจอีกครั้ง ไม่ต้องเริ่มค้นใหม่หากไฟล์ยังอยู่ หากไฟล์หายจริงระบบจะหยุดและแจ้งตำแหน่ง ไม่แทนด้วยไฟล์ชื่อคล้ายกัน

ปุ่ม **เปิดโฟลเดอร์สื่อ B-roll** เปิดโฟลเดอร์ใน Finder/ตัวจัดการไฟล์จริง ไฟล์ที่นำเข้าใหม่จะเก็บใน cli_lab_assets ภายในโปรเจกต์พร้อมทะเบียนสื่อ ไม่ย้ายหรือลบโฟลเดอร์นี้
