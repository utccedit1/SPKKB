# ช่วยด้วยจ้า · Stock Bridge (รุ่นทดสอบ)

ส่วนขยายนี้ทำงานกับแอปช่วยด้วยจ้าในเครื่อง ให้ผู้ใช้เชื่อมบัญชีของตัวเอง ไม่มีรหัส Artlist หรือ Envato ฝังมา

1. ในช่วยด้วยจ้า เปิดแท็บ UTCC + CapCut CLI → บัญชีคลังสื่อ → Artlist → เปิดหน้าเข้าสู่ระบบ
2. ใน Chrome ที่แอปเปิดให้ ไปที่ chrome://extensions เปิด Developer mode แล้ว Load unpacked เลือกโฟลเดอร์ stock_extension ที่แอปแสดง
3. เปิดส่วนขยาย “ช่วยด้วยจ้า · Stock Bridge” วางรหัสเชื่อมที่แอปแสดง แล้วกดเชื่อมและเปิดเว็บ
4. ล็อกอิน Artlist และยืนยัน CAPTCHA ด้วยตัวเอง หากเว็บไซต์ยังวนตรวจสอบ ให้หยุดและติดต่อ Artlist ไม่ต้องปิดระบบป้องกันหรือใช้เครื่องมือข้าม CAPTCHA
5. กดตรวจ/ทำต่อในส่วนขยาย แล้วกดตรวจบัญชีหลังล็อกอินในแอป
6. ในปรับแต่งเพิ่มเติม เปิดค้นและดาวน์โหลด B-roll / เพลงจาก Artlist ก่อนวางแผนและสร้างคลิป

สิทธิ์: หน้าเว็บ Artlist/Envato ที่ระบุไว้ การดาวน์โหลด ที่เก็บรหัสเชื่อมเฉพาะเครื่อง และแอปที่ 127.0.0.1 ไม่มี cookies/debugger/<all_urls> ไม่มีการส่งรหัสผ่าน คุกกี้ หรือ URL ดาวน์โหลดที่มีลายเซ็นกลับแอป

รหัสเชื่อมเป็นกุญแจเฉพาะบริการและผู้ใช้สำหรับแอปในเครื่อง ห้ามแจกพร้อมแอป ห้ามส่งให้ผู้อื่น เก็บเฉพาะเครื่องผู้ใช้ ไม่อยู่ในโฟลเดอร์ส่วนขยาย

การยกเลิกสิทธิ์ส่วนขยายในแอปทำให้รหัสเก่าใช้ไม่ได้ แต่ไม่ใช่การออกจากบัญชีบนเว็บ ผู้ใช้สามารถออกจาก Artlist ใน Chrome และลืมการเชื่อมในส่วนขยายแยกกัน

รองรับ: Artlist เป็นรุ่นทดลอง ยังต้องตรวจการดาวน์โหลดไฟล์สมาชิกจริงทั้งวงจร Envato เปิดหน้าเชื่อมได้ แต่ยังไม่รองรับดาวน์โหลดอัตโนมัติ ไม่ใช้เครดิต AI และไม่กดซื้อแพ็กเกจ

ก่อนแจกใช้งานทั่วไป ควรส่งส่วนขยายตรวจบน Chrome Web Store เพื่อให้ติดตั้งได้ง่าย ไม่ต้องเปิด Developer mode ชุดนี้ยังไม่ใช่ส่วนขยายที่เผยแพร่บน Store
